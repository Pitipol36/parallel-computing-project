After the presentation I tackled the biggest remaining cost: the single-threaded BVH build. The GPU version is Karras's LBVH. Every triangle gets a 63-bit Morton code from its centroid, a radix sort orders them along a space-filling curve, and then one thread per internal node finds its range and split in parallel. A bottom-up pass with atomic counters fits the boxes, and a final pass collapses small subtrees into leaves and flattens the tree into exactly the node layout the render kernels already use. On the Buddha it builds in 5.6 milliseconds, 167 times faster than the CPU SAH builder and 60 times faster than the same LBVH algorithm on one core. The GPU tree is bit-for-bit identical to the CPU LBVH, and every builder renders exactly the same triangle per pixel.
