PCIe

Download the image

Same code on both sides

Ray, box, triangle, traversal and shading are written once as __host__ __device__. The CPU and the optimized kernel run literally the same functions.

Identical rays

A PCG hash of (pixel, sample) seeds each AO ray, sampled without sin/cos, so the CPU and GPU generate bit-identical directions.

No communication

Rays are independent. The costs are warp divergence (different tree paths) and irregular memory access.

6 · BVH ray tracing on CUDA

The BVH is built once on the CPU with the same code as the baseline and uploaded, so both versions do identical work per ray and only the execution model differs. On the GPU, each thread owns one pixel and traces its primary, shadow and AO rays with its own small stack. To make the comparison checkable, the math is shared host-device code and the random numbers are a deterministic hash, so the CPU and GPU shoot exactly the same rays. The interesting GPU costs are divergence, because neighbouring threads take different paths through the tree, and scattered memory reads.
