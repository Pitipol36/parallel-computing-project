For the ablation study there are four kernels behind a command-line flag. Brute force shows that the algorithm matters more than raw parallelism. The naive BVH kernel uses the same tree but a plain array-of-structs layout. The optimized kernel uses aligned float4 loads through the read-only cache, a precomputed inverse direction and nearer-child-first ordering. The persistent-threads kernel launches only enough warps to fill the GPU and lets them grab tiles from a global counter, which targets the imbalance between cheap background pixels and expensive geometry pixels.
