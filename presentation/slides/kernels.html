For the ablation study there are four kernels behind a command-line flag, with the single-core CPU on the first row for reference. Brute force was only feasible on the bunny: 3.6 seconds, while the BVH kernels take about half a millisecond, and even one CPU core with the BVH takes only 38 milliseconds. So the algorithm matters more than raw parallelism. The naive BVH kernel uses the same tree but a plain array-of-structs layout. The optimized kernel uses aligned float4 loads through the read-only cache, a precomputed inverse direction and nearer-child-first ordering; it is about two and a half to three times faster on every model. On the Buddha, the largest model at 1.09 million triangles, the optimized kernel takes 8.3 milliseconds against 937 on the CPU. The persistent-threads kernel launches only enough warps to fill the GPU and lets them grab tiles from a global counter; it makes no real difference on any model. Brute force runs in 8-row strips to stay under the Windows two-second watchdog.
